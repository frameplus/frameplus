# JOBS — 알림 설정 · 동작 (명세 05 알림 · 백그라운드)

## 무엇이 언제 오는가
| 알림 | 조건 | 시간대 | 끄는 곳 |
|---|---|---|---|
| 퇴근하셨어요? (S-05) | 오늘 출근 시각이 있고 퇴근이 비어 있음 | 퇴근 알람 시각(현장 설정 → 없으면 내 설정 → 18:00)부터 30분 간격 3회 | 설정 «퇴근 알람» · 현장 «퇴근 알람» |
| 퇴근 시간 자동 기록 | 3회 알림 뒤(+90분)에도 퇴근이 없으면 퇴근 알람 시각으로 기록 + «맞아요 / 수정» 배너 | 같은 날 저녁 | 위와 같음 (알람을 꺼도 자정이 넘으면 자동 기록) |
| 3일 뒤 입금 예정 | 발송한 청구서의 예정일이 3일 남음 | 08~21시 | 설정 «입금 예정일 · 연체 알림» · 현장 «예정일 알람» |
| 입금 예정일이 지났어요 | 예정일 다음 날부터 1회 → 독촉 화면 링크 | 08~21시 | 위와 같음 |
| n일째 미입금 | 예정일 10일 초과 1회 → 단호한 문안 | 08~21시 | 위와 같음 |
| 오늘 출근 기록이 없습니다 | 평일, 최근 14일 안에 기록이 있는데 오늘 기록 없음 | 19~21시 1회 | 설정 «출근 미기록 알림» |
| 입금, 현장을 지정해 주세요 | «확인 필요» 입금이 3일 지남 (30일 지나면 «제외»로 자동 정리) | 08~21시 | — |

- 모든 알림은 **앱 알림함(홈의 종 아이콘)**에 먼저 쌓이고, 기기에서 «알림 켜기»를 한 사람에게만 푸시로도 간다.
- 21시~07시는 푸시를 보내지 않는다(알림함에만). 같은 알림은 두 번 가지 않는다(중복 키).
- 푸시 «퇴근 기록» 버튼 → 앱이 열리며 현재 시각으로 퇴근 기록(이미 기록돼 있으면 덮어쓰지 않음). «시간 수정» → 기록 수정 화면.

## 운영 설정 (한 번만)
1. 키 생성: `node scripts/jobs-vapid-keys.mjs`
2. Cloudflare Pages → frameplus-erp → Settings → Variables and Secrets
   - `JOBS_VAPID_PUBLIC` (일반 변수), `JOBS_VAPID_PRIVATE` (**Secret**), `JOBS_VAPID_SUBJECT` (`https://www.frameplus.kr`), `JOBS_CRON_SECRET` (**Secret**)
   - 선택: `JOBS_PUSH_BATCH` (크론 1회 푸시 상한, 기본 20)
3. 크론 Worker 배포 — Pages Functions 는 Cron Trigger 가 없다.
   ```bash
   cd workers/jobs-cron
   # wrangler.toml 의 TARGET_URL 을 운영 주소로 확인
   npx wrangler deploy
   npx wrangler secret put CRON_SECRET    # JOBS_CRON_SECRET 과 같은 값
   ```
4. 확인: 앱 설정 → «알림 켜기» → «테스트 알림». Worker 로그(`npx wrangler tail jobs-cron`)에 10분마다 `jobs-cron 200 {...}`.

키를 바꾸면 기존 기기 구독이 무효가 되어 사용자가 «알림 켜기»를 다시 눌러야 한다. 키가 없으면 푸시만 빠지고 알림함은 그대로 동작한다.

## 비용 · 한도 [확인 필요]
- 웹 푸시 발송 비용 0원(브라우저 푸시 서비스 무료). 크론 Worker 는 10분 × 144회/일 = 월 약 4,300 요청 — Workers 무료 한도(일 10만 요청) 안.
- 크론 1회 CPU 시간을 줄이려고 푸시는 큐로 나눠 보낸다(기본 20건/회 → 시간당 120건). 파일럿 5명 기준 충분.
