# JOBS — 카카오 알림톡 템플릿 (심사 제출용 초안)

알림톡은 **카카오 비즈니스 채널 + 템플릿 사전 심사**가 필요합니다. 심사 통과 전까지 앱의 «카카오톡» 보내기는 문자(LMS)로 대체되며, 앱에 그렇게 표시됩니다.
심사 통과 후 Cloudflare Pages 환경변수에 템플릿 ID를 넣으면 코드 변경 없이 알림톡으로 전환됩니다(`src/jobs/api.ts` — 변수명은 아래 표와 일치해야 함).

| 환경변수 | 용도 | 변수 |
|---|---|---|
| `JOBS_KAKAO_TPL_INVOICE` | 청구서 보내기 (S-10) | `#{업체}` `#{현장}` `#{기간}` `#{청구금액}` `#{세액}` `#{실수령}` `#{예정일}` `#{링크}` |
| `JOBS_KAKAO_TPL_DUNNING` | 미정산 독촉 (S-14) | `#{업체}` `#{현장}` `#{기간}` `#{잔액}` `#{예정일}` `#{경과일}` `#{링크}` |
| `JOBS_KAKAO_TPL_QUOTE` | 견적서 보내기 (S-09) | `#{업체}` `#{현장}` `#{기간}` `#{합계}` `#{부가세}` `#{링크}` |

기존 `KAKAO_PF_ID`(카카오 채널 프로필 키)와 `SOLAPI_*`를 그대로 사용합니다. 발송 실패 시 Solapi 설정(`disableSms: false`)에 따라 문자로 대체 발송됩니다.

## 등록 절차 [확인 필요: 솔라피 콘솔 기준 최신 절차]
1. 카카오 비즈니스 채널 개설 · 비즈니스 인증 (사업자등록증) — 1~3일
2. 솔라피 콘솔 → 카카오 채널 연동 → 발신프로필 등록 (`KAKAO_PF_ID`)
3. 아래 템플릿 3종 등록 → 심사 (영업일 1~3일). 반려 사유로 흔한 것: 광고성 문구, 변수 과다, 버튼 URL 도메인 미등록
4. 승인된 템플릿 코드를 환경변수에 입력 → 재배포 없이 적용(Pages 환경변수는 다음 요청부터 반영)

## 템플릿 1 — 청구서 (JOBS_KAKAO_TPL_INVOICE)
```
[JOBS 청구서] #{업체} 담당자님,
#{현장} #{기간} 청구서를 보내드립니다.

청구 금액 #{청구금액}원
세액공제 #{세액}원
실수령액 #{실수령}원
입금 예정일 #{예정일}

아래 버튼에서 청구서를 확인하고 PDF로 저장할 수 있습니다.
```
버튼: «청구서 보기» — 웹링크 `#{링크}` (모바일 · PC 동일)

## 템플릿 2 — 입금 요청 (JOBS_KAKAO_TPL_DUNNING)
```
[JOBS] #{업체} 담당자님,
#{현장} #{기간} 청구서의 잔액 #{잔액}원이
입금 예정일(#{예정일})로부터 #{경과일}일째 미입금입니다.

확인 후 입금 부탁드립니다. 입금이 어려우시면 일정을 회신해 주세요.
```
버튼: «청구서 보기» — 웹링크 `#{링크}`

## 템플릿 3 — 견적서 (JOBS_KAKAO_TPL_QUOTE)
```
[JOBS 견적서] #{업체} 귀하,
#{현장} #{기간} 견적서를 보내드립니다.

견적 합계 #{합계}원 (#{부가세})

아래 버튼에서 견적서를 확인하고 PDF로 저장할 수 있습니다.
```
버튼: «견적서 보기» — 웹링크 `#{링크}`

## 비용 [확인 필요: 솔라피 요금표]
- 알림톡 건당 약 8~15원, LMS 대체 발송 시 약 30원
- [가정] 파일럿 5명 × 월 청구서 4건 + 독촉 2건 = 월 30건 → 월 1,000원 미만
