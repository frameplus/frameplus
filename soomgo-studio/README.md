# 숨고 상담 스튜디오 — 관리 화면 프로토타입

숨고로 영업하는 업체에 판매할 상담 자동화 프로그램의 **관리 화면 UI 프로토타입**이다.
목업 데이터로 화면 구성과 흐름만 확인한다. 숨고 연동, 서버 저장, 로그인, 결제, 문자·알림톡 발송은 없다.

`public/` 밖에 있어 ERP 배포(Cloudflare Pages)에 포함되지 않는다.

## 실행

```bash
cd soomgo-studio && python3 -m http.server 8811   # http://localhost:8811
```

## 화면

| 주소 | 화면 | 확인할 것 |
|---|---|---|
| `#inbox` | 상담 목록 + 고객 상세 | 상태 6종 필터, 요청서·발송 10건·대화, 담당자 이어받기(자동답변 중지), 보류 항목 이어서 발송 |
| `#categories` | 카테고리 관리 | 인사·질문·미팅 문구, 견적 기준. 입력하면 오른쪽 채팅 미리보기가 바로 바뀜 |
| `#assets` | 첨부자료 관리 | 실제 전송 순서(1~10번), 사진 교체·삭제·끌어서 정렬 |
| `#connect` | 연결·알림 설정 | 숨고 연결 상태, 자동응대, 담당자별 문자/알림톡, 알림 문구, 중복 차단 기록 |
| `#company` | 업체 설정 | 상호·담당자·연락처·홈페이지, 직원 계정 |
| `#seller` | 판매자 운영 | 구매 업체 결제·이용 기간·사용량·발송 실패 |

## 파일

- `data.js` 목업 데이터 (가상의 고객·업체. 견적 기준 금액은 예시값)
- `app.js` 화면 렌더링과 상호작용
- `styles.css` 디자인 토큰과 레이아웃

## 디자인 기준

- 레퍼런스(Refero): Lemni 인박스(목록·대화·상세 3단), Kit 시퀀스 편집기(편집 + 설정), ManyChat(단계별 메시지와 미리보기), Intercom 채널 설정(연결 상태 카드)
- 색은 종이색 바탕에 먹색 글자. 주홍은 "사람이 움직여야 하는 일"(통화 요청, 이어받기, 재연결, 발송 실패)에만 쓴다.
- 글꼴은 IBM Plex Sans KR, 숫자·시각은 IBM Plex Mono.

## 다음 단계에서 정할 것

- 숨고 약관상 제3자 프로그램의 자동 입력·연속 발송 허용 범위
- 일회성 판매(30만 원) vs 월 구독
- 업체별 서버 저장 구조(계정·문구·사진·채팅·알림 수신자 분리)
